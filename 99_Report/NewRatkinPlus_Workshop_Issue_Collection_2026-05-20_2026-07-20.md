## 1. 실행·세이브·월드 생성

### NRP-CMT-01. 월드 생성 시 다른 팩션 누락

- 랫킨 모드를 포함하면 월드에 랫킨 팩션만 생성된다는 보고가 있음.
- 다수의 팩션이 사라지거나 일부 팩션이 생성되지 않는다는 보고가 있음.
- 중세·마법 등 자체 팩션을 추가하는 모드와 함께 사용할 때 모든 추가 팩션 생성이 실패한다는 내용이 있음.
- 새 게임에서 팩션 생성기를 사용해도 누락된 팩션을 생성할 수 없었다는 내용이 있음.
- 랫킨을 단독으로 사용하거나 랫킨을 제외하면 정상화된다는 사용자 관찰이 있음.

### NRP-CMT-02. RimWorld 1.5 호환성 및 기존 세이브 손상

- 업데이트 후 1.5 환경에서 기존 세이브가 정상적으로 동작하지 않는다는 보고가 있음.
- 폰이 보이지 않거나 머리만 표시되는 현상이 언급됨.
- 아이템이 흰색 사각형으로 표시되는 현상이 언급됨.
- 텍스처와 음향이 대량으로 누락된다는 보고가 있음.
- 모드를 비활성화하면 세이브가 다시 열리지만 랫킨 관련 개체는 사라진다는 내용이 있음.
- 1.5용 구버전으로 수동 다운그레이드하면 복구된다는 사용자 해결 사례가 있음.

### NRP-CMT-03. RimWorld 1.4 지원 제거로 기존 게임 중단

- 1.4 선택지가 사라진 후 진행 중이던 1.4 세이브가 깨졌다는 보고가 있음.
- 기존 사용자를 위해 1.4 버전을 다시 제공해 달라는 요청이 있음.

### NRP-CMT-04. 1.6 환경에서 오류 및 신규 게임 시작 불가

- 1.6에서 오류 로그가 반복 출력된다는 보고가 있음.
- 모드 및 선행 모드를 재구독해도 신규 게임을 시작할 수 없었다는 내용이 있음.
- 모든 DLC 중 Anomaly를 제외한 환경에서 발생했다는 사례가 있음.
- RimWorld 업데이트로 일부 Harmony 기능이 깨졌다는 추정과, 다른 모드에서는 Harmony가 정상이라 Ratkin 문제라는 추정이 함께 존재함.

### NRP-CMT-05. 세이브·신규 게임·시나리오 생성 실패

- 기존 세이브와 신규 게임이 모두 열리지 않는다는 보고가 있음.
- 어떤 시나리오도 생성할 수 없고 모드 설정이 초기화됐다는 내용이 있음.
- 다수의 다른 모드를 함께 설치한 상태에서 Ratkin 등록 후 오류가 발생했다는 포괄적인 보고가 있음.

## 2. 종족 판정·모집·이벤트

### NRP-CMT-06. 랫킨 모집 이벤트에서 인간 생성

- 방랑자 합류 등 랫킨 모집 기회가 발생해야 하는 이벤트에서 인간만 등장한다는 반복 보고가 있음.
- 일반 랫킨과 Oberonia Aurea 랫킨 모두 모집 후보로 나오지 않는다는 내용이 있음.
- 드롭포드 알림에는 랫킨이 도착한다고 표시되지만 실제로는 인간이 생성된다는 사례가 있음.
- 과거와 비교해 랫킨 모집 이벤트가 발생하지 않도록 동작이 변경된 것인지 묻는 내용이 있음.

### NRP-CMT-07. 랫킨이 인간 종족으로 판정됨

- 일부 초기 랫킨 또는 야생 랫킨의 정보상 종족이 인간으로 표시된다는 보고가 있음.
- 정상 개체는 랫킨으로 표시되지만 문제 개체는 인간으로 표시된다는 비교가 있음.
- 유전자형은 초기 랫킨으로 표시되지만 종족 판정과 외형은 인간이라는 사례가 있음.
- 해당 판정 문제와 함께 랫킨 의류 착용 불가 및 인간 얼굴 표시가 발생한다는 내용이 있음.

### NRP-CMT-08. 야생 랫킨 길들이기 음식 부족 판정

- 길들이기에 필요한 음식이 충분한데도 음식 부족으로 길들일 수 없다는 메시지가 표시됨.
- 어떤 음식 종류가 길들이기 조건을 만족하는지 알 수 없다는 문의가 있음.

## 3. 의류·장비 착용

### NRP-CMT-09. 랫킨이 랫킨 전용 의류를 착용하지 못함

- 랫킨 폰이 랫킨 의류를 착용할 수 없다는 보고가 있음.
- 초기 랫킨을 선택한 상태에서 랫킨 종족 의류를 입을 수 없다는 사례가 있음.
- 인간으로 잘못 판정된 야생 랫킨에게 랫킨 의류를 입히면 인간은 착용할 수 없다는 메시지가 나온다는 내용이 있음.

### NRP-CMT-10. NPC·상단 랫킨이 인간 의류 착용

- 랫킨 NPC가 파카, 인간용 털모자 등 일반 인간 의류를 입고 등장한다는 반복 보고가 있음.
- 랫킨 전용 의류만 입도록 제한하는 설정을 찾을 수 없다는 문의가 있음.
- 플레이어 식민지의 랫킨은 의상 프리셋으로 제한할 수 있다는 사용자 답변이 있음.
- 다른 팩션의 랫킨이나 방문 상단에는 같은 방식을 적용할 수 없다는 후속 내용이 있음.

### NRP-CMT-11. 랫킨 소드오프 샷건 착용 제한 반전

- 랫킨 소드오프 샷건을 랫킨이 장착하지 못한다는 보고가 있음.
- 비랫킨은 해당 무기를 장착할 수 있다는 내용이 있음.
- 무기 설명의 인간 사용 불가 문구와 실제 동작이 반대라는 지적이 있음.

### NRP-CMT-12. 모자·헬멧 착용 시 머리카락 또는 귀 숨김

- 모자를 착용하면 랫킨 머리카락이 모두 숨겨져 대머리처럼 보인다는 내용이 있음.
- 머리카락을 숨기지 않게 설정하는 방법을 찾을 수 없다는 문의가 있음.
- 특정 철제 기병 헬멧 착용 시 귀가 사라진다는 보고가 있음.
- 헬멧 비표시 모드를 함께 사용해도 귀가 복구되지 않는다는 사례가 있음.

### NRP-CMT-13. 이념 지도자 의상 요구사항에 랫킨 의류 노출

- `1.6/Patches/PreceptDef_RoleApparel_Patch.xml`로 인해 랫킨 의류가 모든 문화의 지도자 의상 후보에 들어갈 수 있다는 보고가 있음.
- 다른 종족도 랫킨 전용 의류를 지도자 필수 복장으로 요구받을 수 있다는 내용이 있음.
- 언급된 항목에는 왕실 로브, 수녀 드레스, 흰 코트, 프릴 원피스, 플랫 컬러 코트, 왕관, 베일, 헤어 코사지 및 리본 헤어밴드 등이 포함됨.

## 4. 외형·렌더링

- 귀와 꼬리가 모두 표시되지 않는다는 사례가 있음.

### NRP-CMT-16. `[NL] Facial Animation` 얼굴 덮어쓰기

- 초기 재배 능력보다 철 곡괭이를 직접 제공하는 편이 낫다는 제안이 있음.

### NRP-CMT-35. 신규 총기의 근접 성능과 총검 특색 감소

- 신규 총기의 근접 성능이 낮다는 의견이 있음.
- 기존 랫킨 총기의 근접·원거리 겸용 및 총검 특색이 약해지고 장비가 동질화됐다는 우려가 있음.

## 검토 시 유의사항

- 동일 증상이 여러 원인에서 발생할 수 있으므로 항목 간 중복 가능성이 있음.
- 종족 판정, 인간 의류 착용, 인간 얼굴, 귀·꼬리 누락 및 모집 이벤트의 인간 생성은 하나의 공통 원인일 가능성도 있으나 이 문서에서는 별도 현상으로 유지함.
- 팩션 생성 실패와 외형 누락에 대해 다른 모드 충돌 가능성이 언급됐지만 정확한 모드 목록과 로그는 제공되지 않음.
- 1.4·1.5·1.6 보고가 함께 포함되어 있으므로 버전별 재현 환경을 분리해야 함.
- 요청·설정 문의·밸런스 의견은 오류 보고와 구분했지만, 채택 여부는 판단하지 않음.
